MiniMax H3 模型概览
MiniMax H3 是 2026 年 7 月 31 日发布的全模态视频生成模型（海螺 AI 3.0）， 支持文本/图像/视频/音频多模态输入，输出 2K 分辨率、最长 15 秒、24FPS 视频及 32kHz 立体声音频。 注意：H3 不是传统文本 LLM，而是视频生成模型。

模型结构与文件组成
H3 包含两个独立任务 checkpoint：FL2VA（文生视频）和 Ref2VA（参考生视频），各自约 135GB。
MiniMax-H3/ # 仓库根目录 ~498GB ├── FL2VA/ # 文生视频任务 ~135GB │ ├── model_index.json │ ├── processor/ # 多模态预处理器 │ ├── tokenizer/ # 分词器 │ ├── text_encoder/ # Qwen3-VL-32B 编码器 ~25GB │ ├── transformer/ # DiT 核心生成模型 │ ├── visual_vae/ # 视频VAE 4.9GB │ └── audio_vae/ # 音频VAE 0.6GB └── Ref2VA/ # 参考生视频任务 ~135GB └── (结构同FL2VA) # ComfyUI 量化版文件 (Comfy-Org/MiniMax-H3) ComfyUI/models/ ├── diffusion_models/ │ ├── minimax_h3_fl2va_pruned_int8_convrot.safetensors 19.5 GB │ └── minimax_h3_ref2va_pruned_int8_convrot.safetensors ~19.5 GB ├── text_encoders/ │ └── qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors 14.6 GB └── vae/ ├── minimax_h3_video_vae_fp16.safetensors 4.9 GB └── minimax_h3_audio_vae_fp32.safetensors 0.6 GB
重要提示
FL2VA 和 Ref2VA 是两个独立分区，各自约 135GB，不能混用。
H3-Context-IR（多模态预处理）和 H3-Regenerate-2K（2K 再生成）模块未开源，仅提供 API。
MiniMaxAI/MiniMax-H3 仓库需接受社区许可协议后才能下载；Comfy-Org/MiniMax-H3 不需要协议。

模型下载
根据部署框架选择对应仓库下载。MiniMaxAI 仓库需先在 HuggingFace 页面接受许可协议。
方式一 下载 BF16 全精度（SGLang / vLLM-Omni / diffusers）
# 设置国内镜像加速
export HF_ENDPOINT=https://hf-mirror.com

# 下载 FL2VA (文生视频) 约135GB
huggingface-cli download MiniMaxAI/MiniMax-H3 \
  --include "model_index.json" "FL2VA/*" \
  --local-dir ./MiniMax-H3

# 下载 Ref2VA (参考生视频) 约135GB
huggingface-cli download MiniMaxAI/MiniMax-H3 \
  --include "model_index.json" "Ref2VA/*" \
  --local-dir ./MiniMax-H3

# 下载全部 (两个分区) 约498GB
huggingface-cli download MiniMaxAI/MiniMax-H3 \
  --local-dir ./MiniMax-H3
方式二 下载 ComfyUI 量化版（INT8/NVFP4）约 40-50GB
# 下载 FL2VA 量化版
huggingface-cli download Comfy-Org/MiniMax-H3 \
  --include "FL2VA/*" \
  --local-dir ./ComfyUI/models/diffusers/MiniMax-H3

# 文件需同时放置到两个目录
cp -r ./ComfyUI/models/diffusers/MiniMax-H3/* \
      ./ComfyUI/models/MiniMax-H3/
方式三 ModelScope 魔搭社区下载
# 安装 modelscope
pip install modelscope

# 下载完整模型
modelscope download MiniMaxAI/MiniMax-H3 \
  --local_dir ./MiniMax-H3
方式四 diffusers 自动下载（代码内自动拉取）
# Python 代码中自动下载所需组件
from diffusers import ModularPipeline

pipeline = ModularPipeline.from_pretrained("MiniMaxAI/MiniMax-H3")
下载注意事项
1. MiniMaxAI/MiniMax-H3 需要在 HuggingFace 页面接受社区许可协议，否则下载会报权限错误。
2. 许可协议排除地域：欧盟、英国、韩国、美国。其他地区可正常使用。
3. Comfy-Org/MiniMax-H3 不需要接受社区协议，可直接下载。
4. 全精度下载约 498GB，确保磁盘空间充足（建议 1TB+ NVMe SSD）。
5. 国内用户建议使用 hf-mirror.com 镜像或 ModelScope 加速下载。

并行策略说明
TP (Tensor Parallel)：张量并行，将模型权重切分到多卡
USP (Ulysses Sequence Parallel)：序列并行，将序列维度切分到多卡
Ring：环形通信，用于跨卡数据交换
VAE Patch Parallel：VAE 的分块并行，加速视频解码
